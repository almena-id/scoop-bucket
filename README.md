# Almena ID Scoop bucket

[Scoop](https://scoop.sh) manifests of [Almena ID](https://almena.id).

```powershell
scoop bucket add almena https://github.com/almena-id/scoop-bucket
scoop install almena/almena
```

| Manifest | What it is | Platforms |
|---|---|---|
| `almena` | [Command-line client](https://github.com/almena-id/almena) of the Almena ID platform | Windows (x86_64) |

`scoop update` brings the newest version distributed. Manifests install the
signed binaries of each project's GitHub releases as they are; nothing is
built here.

Issues with a manifest go to the project it installs.
